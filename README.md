# weareantenna/.github

Default PR template and PR rules for the repos in `weareantenna`. A repo with its own `pull_request_template.md` or `CONTRIBUTING.md` overrides these.

- `pull_request_template.md`: the default PR description
- `CONTRIBUTING.md`: branch names, titles, screenshots, what to run before opening a PR
- `scripts/pr-screenshots.sh`: upload PR screenshots without putting images in the repo history
